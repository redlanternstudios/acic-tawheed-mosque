# Afghan Community Islamic Center

## Tawheed Mosque · San Diego

A premium, welcoming digital home rooted in Afghan heritage and open to the entire Ummah.

### Current build

- Next.js App Router
- TypeScript
- Responsive public website foundation
- First visit, prayer times, Open Masjid, children and families, new Muslims, community support, events, media, about, donate, contact, and admin foundation routes
- Vercel-ready configuration

### Brand direction

Afghan hospitality × Apple-level simplicity × San Diego openness.

### Development

```bash
npm install
npm run dev
```

The production build requires approved mosque assets, verified prayer data, board-approved contact and donation methods, Supabase configuration, and religious content review before public launch.
